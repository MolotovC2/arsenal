## BOFs

Legend for arguments syntax:

- z: null-terminated and encoded string
- Z: null-terminated wide-char string
- i: 4-byte integer
- s: 2-byte short integer
- b: binary data
- f (prefix): boolean flag (1=true, 0=false)
- e (prefix): enumeration, options follow after second colon
- a (prefix): array, usually preceeded by an argument specifying the array length
- [](brackets): optional argument
- =X (suffix): default value
- ==X (suffix): literal value, usually used for BOFs that take a command argument
